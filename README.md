# ICT-Roads
This is a mock website of the State Department for Roads
 State Department for Roads - Web Portal

An official portal template for the **State Department for Roads (Ministry of Roads and Transport, Republic of Kenya)**. This website provides public access to core mandates, major road infrastructure projects, procurement notices, tenders, and departmental contacts.

---

## 📌 Features

* **Header & Navigation Bar:** Includes official branding, contact email/phone, and quick links to key pages.
* **Hero Banner:** Visual highlight emphasizing infrastructure goals and a call-to-action button for exploring projects.
* **Core Mandate & Pillars:** Grid section detailing trunk highways, routine maintenance, axle load regulation, and PPP investments.
* **Announcements & Tenders Table:** Clear tabular view listing reference numbers, tender descriptions, closing dates, and action links.
* **Footer:** Contains location details (Works Building, Ngong Road, Nairobi), operating hours, and quick navigation links.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure (`<header>`, `<nav>`, `<section>`, `<table>`, `<footer>`).
* **CSS3:** Custom styles for navigation, layout cards, responsive typography, and tabular styling.
